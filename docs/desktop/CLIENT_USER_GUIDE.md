# Using Copilot

Copilot works exactly as it did in the browser. The Search, My sheet and Potential customers tabs,
the filters, the results and the Excel downloads are all the same. This guide covers only what is
different now that Copilot is a Windows program.

## Opening Copilot

Open Copilot from the **Start menu** or the **desktop shortcut**. It opens in its own window, with
no browser needed. If Copilot is already open, opening it again brings the open window to the front.

## Your name

Copilot no longer asks who is working when it starts. It uses your Windows user name, shown at the
top right. The name labels your searches and your sheet, and starts the suggested name of your
downloads. To change it, click the name.

## Downloading Excel files

When you download a spreadsheet, Windows asks where to save it, with the name you chose already
filled in. Downloads split into several parts arrive as a single .zip file, as before.

## Links

**Google Maps**, **Gov.uk record** and **Companies House** links open in your normal web browser.

## Keeping the data up to date

As before, the footer shows which version of each dataset you have. Choose **Check for updates**
to look for newer data and install it. Searches keep working while it installs.

Copilot also installs new data automatically between 1 am and 5 am, but only if the computer is on
and Copilot is open at that time. If your PC is usually off overnight, use **Check for updates**
now and then. The footer tells you when new data is available.

## Updates to Copilot itself

When a new version of Copilot is ready, a notice appears in the bottom-right corner:

- **Restart now** installs it straight away. If a search or a data download is still running,
  Copilot asks you to wait until it has finished.
- **Later** installs it automatically the next time you close Copilot.

Your data, sheets and settings are always kept.

## Trial and activation

Your trial lasts **2 days** from the first time Copilot starts. When it ends, Copilot shows a
**"Your free trial has ended"** screen and new searches stop. Nothing is deleted: your data, sheets
and downloaded files are all kept.

Once Copilot is activated, choose **Check again** on that screen, or simply reopen Copilot. It
unlocks by itself, with no reinstalling. An activated Copilot needs an internet connection at least
once every 14 days to confirm its licence.

Other messages you might see:

| Message | What to do |
|---|---|
| Connect to the internet to start | The first start needs internet. Connect, then choose **Check again**. |
| Copilot needs to check its licence | Copilot has been offline too long. Connect, then choose **Check again**. |
| The licence server isn't responding | Usually temporary. Choose **Check again** in a few minutes. |
| Check your computer's date and time | Correct the clock in Windows settings, then choose **Check again**. |
| Access has been turned off | Contact your Copilot administrator. |

## If something goes wrong

Choose **Save diagnostics** on any Copilot message screen. This saves Copilot's log files as one
.zip file. Send it to your Copilot administrator. The logs contain no passwords or keys.

If Copilot doesn't open at all, send the files in `C:\Users\<you>\AppData\Local\Copilot\logs` instead.
